📌 Official User Guide Memo (使用要点备忘):

  1. 同一个 App 所有人通用：公众、患者、家属与注册护士均下载同一款 Assura Nursing 应用。
  2. 公众与家属 (无需登录)：直接打开 App 即可查询全槟城上门护理收费、器材指南与医院急诊 GPS 路线。
  3. 患者家属关联病历 (Case Link)：已有护理个案的家庭，在门户输入 Case Access Code (如 ASN-8821) 或手机号，即可实时查看护士每次上门记录的 MEWS 生命体征评分与给药打卡。
  4. 医护人员专属门户 (Staff Portal)：护士与主管请点击「🩺 Staff ID」标签，输入专属工号 (如 ASN-001 / ASN-002) 与 PIN 登录接单、记录生命体征与排班。
